# Nibble 陪伴小生物

模仿 [Nibble](https://nibble.dev/) 玩法的 VS Code / CodeBuddy 陪伴小插件。
一只彩色像素小生物常驻**底部面板**与**状态栏**，你每次向 AI 提问它就攻击一次野生敌人；
打空血击败/捕获后刷新更强的下一只，等级/经验/战绩与当前敌人**跨会话存档**。

> 视觉语言参照 spinlings.dev（深色底 / 橙色野生 / 红色攻击），像素素材为原创（3 张 AI 生成的敌人素材 CC0 + 玩家小生物为作者自摄小狗像素化），未复制任何第三方素材。

## 功能

- **底部面板视图**：24×24 真彩像素小生物，待机上下浮动 / 攻击前冲 / 击败像素消散，带 HP 条与战斗日志
- **状态栏**：`♥ Lv1 ████░░░░ 24/40 蝙蝠`，随战斗实时变化，点击直接展开面板
- **战斗循环**：提问即攻击一次 → 敌人掉血 → 血量归零则击败/捕获 → 刷新更硬的下一只
- **Roguelite 成长**：攻击力随等级提升，击败获得经验，敌人 HP 与稀有度随等级提升
- **稀有度**：普通=原色，稀有=闪烁亮点像素，史诗=品红染色，传说=金色染色
- **跨会话存档**：等级 / 经验 / 攻击次数 / 击败数 / 当前敌人

## 命令

| 命令 | 说明 |
|---|---|
| `Nibble: 显示像素小生物（底部面板）` | 展开底部停靠视图 |
| `Nibble: 在编辑器标签页中打开` | 放大到编辑器标签页 |
| `Nibble: 重置等级/经验/战绩` | 清空进度重新开始 |
| `Nibble: 显示/隐藏状态栏小生物` | 切换状态栏显示 |
| `Nibble: 关于匿名统计（发什么 / 如何关闭）` | 查看当前统计状态、上次上报时间，并一键关闭统计或重置匿名 ID |

## 设置

| 设置项 | 默认 | 说明 |
|---|---|---|
| `nibble.statusBar` | `true` | 在状态栏显示小生物 |
| `nibble.autoOpenPanel` | `true` | 启动时自动展开底部面板 |
| `nibble.tickMs` | `400` | 刷新间隔（毫秒） |
| `nibble.telemetry` | `true` | 发送匿名激活统计（仅匿名 ID + 版本号，每天最多 1 次）；设为 `false` 后不再联网 |

## 隐私

**本扩展唯一会联网的地方是"匿名激活统计"**，且从添加它的那个版本起就在更新日志（`CHANGELOG.md`）里公开说明。

- 只发送 **2 个字段**：本机随机生成的**匿名 ID**（与账号/机器无关，可一键重置）+ **扩展版本号**。
- **不发送**：代码、文件内容、文件路径、项目名、提问内容、账号、邮箱、机器名、操作系统、地理位置。
  服务端**不保存 IP**，只累加"当天上报次数 / 当天去重活跃数 / 各版本次数"。
- **频率**：每台机器每天最多 1 次（当天首次打开 IDE 时）。上报失败静默忽略，不影响任何功能。
- **关闭方式**（任一即可）：把 `nibble.telemetry` 设为 `false`；或运行命令 `Nibble: 关于匿名统计（发什么 / 如何关闭）` 点「关闭统计」；或关闭 IDE 的全局遥测，本扩展同样不会发送。
- 除此之外，扩展**不读取**你的代码、提示词或文件内容，只读自己那份游戏存档（`save.json`）。

## 战斗推进怎么来的

扩展只负责**显示**；"提问即攻击"的节拍由同系列的 **CodeBuddy 插件**（`nibble-cb/plugins/nibble`）通过
`UserPromptSubmit` hook 驱动，两者读写同一份存档：

```
${CODEBUDDY_PLUGIN_DATA}/save.json
（默认 ~/.codebuddy/plugins/data/nibble/save.json）
```

因此展示是**常驻、自动动画、零 token**的；即使 hook 未安装，也可以用 `/nibble` 风格的手动攻击或命令推进。

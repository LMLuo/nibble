# Nibble · 住在编辑器里的像素小狗

一只住在**底部面板**与**状态栏**的像素小狗：你每次向 AI 提问（或保存文件），它就**打一只怪**——
升级、掉武器、收集图鉴，等级与进度**跨会话保存**。

## 它是谁：我的狗「拾玖」

游戏里这只像素小狗，是照着我家的狗画的——**约克夏串串**，名字叫 **拾玖**。

<p><img src="https://github.com/LMLuo/nibble/raw/main/vscode-extension/media/dog-shijiu.jpg" width="280" alt="拾玖的照片"></p>

把它的照片手工点成 24×24 像素（11 色），就成了游戏里的样子。它平时陪我写代码，现在也顺便帮你打工。

## 功能

- **底部面板**：24×24 真彩像素小狗，待机上下浮动 / 攻击前冲 / 击败像素消散，带 HP 条与战斗日志
- **状态栏**：`♥ Lv1 ████░░░░ 24/40 蝙蝠`，随战斗实时变化，点击展开面板
- **战斗循环**：提问即攻击 → 敌人掉血 → 血量归零则击败/捕获 → 刷新更强的下一只
- **Roguelite 成长**：攻击力随等级提升；敌人 HP 与稀有度随等级提升（普通 / 稀有 / 史诗 / 传说）
- **武器库**：击败**必掉 1 把武器**（普通 70% / 稀有 22% / 史诗 7% / 传说 1%，40 次保底），
  80 把武器**各有独立像素图与一段小故事**；「🎒 武器库」页按稀有度分组展示收集进度
- **装备展示**：在武器库详情卡点「装备此武器」，战斗页的**装备槽**就换成它（图鉴里有 ★ 标记）
- **跨会话存档**：等级 / 经验 / 战绩 / 武器库

## 命令

| 命令 | 说明 |
|---|---|
| `Nibble: 显示像素小生物（底部面板）` | 展开底部停靠视图 |
| `Nibble: 攻击一次` | 手动补一刀 |
| `Nibble: 打开武器库` | 查看收集进度与武器故事、装备武器 |
| `Nibble: 在编辑器标签页中打开` | 放大到编辑器标签页 |
| `Nibble: 重置等级/经验/战绩` | 清空进度重新开始 |
| `Nibble: 显示/隐藏状态栏小生物` | 切换状态栏显示 |
| `Nibble: 关于匿名统计（发什么 / 如何关闭）` | 查看统计状态、一键关闭或重置匿名 ID |

## 设置

| 设置项 | 默认 | 说明 |
|---|---|---|
| `nibble.triggerMode` | `hook` | 战斗节拍来源：`hook`（配套插件提问即攻击）/ `onSave`（保存文件即攻击）/ `manual`（仅手动） |
| `nibble.statusBar` | `true` | 在状态栏显示小生物 |
| `nibble.autoOpenPanel` | `true` | 启动时自动展开底部面板 |
| `nibble.tickMs` | `400` | 刷新间隔（毫秒） |
| `nibble.telemetry` | `true` | 发送匿名激活统计（仅匿名 ID + 版本号，每天最多 1 次）；设为 `false` 后不再联网 |

> 只装扩展、没有配套插件时，把 `nibble.triggerMode` 改成 `onSave` 即可独立使用。

## 隐私

**本扩展唯一会联网的地方是"匿名激活统计"**，且从添加它的那个版本起就在更新日志里公开说明。

- 只发送 **2 个字段**：本机随机生成的**匿名 ID**（与账号/机器无关，可一键重置）+ **扩展版本号**。
- **不发送**：代码、文件内容、文件路径、项目名、提问内容、账号、邮箱、机器名、操作系统、地理位置。
  服务端**不保存 IP**，只累加"当天上报次数 / 当天去重活跃数 / 各版本次数"。
- **频率**：每台机器每天最多 1 次。上报失败静默忽略，不影响任何功能。
- **关闭方式**（任一即可）：把 `nibble.telemetry` 设为 `false`；或运行 `Nibble: 关于匿名统计` 点「关闭统计」；或关闭 IDE 全局遥测。
- 除此之外，扩展**不读取**你的代码、提示词或文件内容，只读自己那份游戏存档。

## 战斗推进怎么来的

扩展只负责**显示**。"提问即攻击"的节拍由同系列的 **CodeBuddy 插件**（仓库 `plugins/nibble`）通过
`UserPromptSubmit` hook 驱动，两者读写同一份存档：

```
${CODEBUDDY_PLUGIN_DATA}/save.json
（默认 ~/.codebuddy/plugins/data/nibble/save.json）
```

因此展示是**常驻、自动动画、零 token** 的；未装插件时可用 `onSave` / `manual` 模式或命令推进。

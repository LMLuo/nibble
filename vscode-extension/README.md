**提问即攻击。** 你每次向 AI 提问（或保存文件），这只住在**底部面板 / 状态栏**的像素小狗就自动打掉一只
「编程 Bug」怪——升级、掉武器、捡技能书、收集图鉴，等级与进度**跨会话保存**。连续提问还会累积**连击**：
光环在脚下亮起，专注看得见。怪物也会反击：血量见底只是被击退一场，不扣任何东西。常驻、自动动画、**零 token**。

## 功能

- **底部面板**：24×24 真彩像素小狗，待机上下浮动 / 攻击前冲 / 击败像素消散，带经验条与战斗日志
- **状态栏**：`♥ Lv1 ████████ 36/36 空指针幽灵`（心形条是**玩家 HP**，tooltip 里另给敌方 HP），随战斗实时变化，点击展开面板
- **战斗循环**：提问即攻击 → 敌人掉血 → 血量归零则击败 → 刷新下一只；敌人没死就反击一次
- **出手有演出**：每次施放拆成「起手 → 生成 → 命中 →（追击）→（反击）」——命中那一拍才结算血条、玩家 HP 与击杀；
  12 个招式原语（落雷 / 直刺 / 斩击 / 爆发 / 液滴 / 印戳 / 法阵 / 漩涡 / 层叠 / 字块 / 回旋 / 骤雨）逐本指派，
  击杀时把怪打飞、从它自己的像素里抠出碎块抛散，掉技能书时书沿抛物线飞进技能槽
- **连击（Combo）**：相邻攻击间隔 ≤10 分钟即累积连击——≥10 连攻击最多 +30%、脚下亮起光环、头顶浮现 `×N`；
  ≥25 连转亮金并加速武器保底；≥50 连触发超载演出。断连静默归零、无惩罚，<10 连完全隐形
- **40 只「编程 Bug」怪物**：命名与故事全部取材自真实 Bug——小怪（空指针幽灵 / 无尽轮回蛇 / 差一错虫 …）、
  精英（内存泄漏巨蟒 / 竞态幽灵 / 死锁蛛 …）、头目（段错误泰坦 / 熵增病毒 / 祖传代码巨像 …）
- **难度分级**：怪物 HP 按 层级 × 稀有度 × 等级 三重缩放（小怪 ×1.0 / 精英 ×2.0 / 头目 ×3.6）；
  共 **8 种机制**——护甲、闪避、自愈、护盾、分裂，以及只给精英与头目的**尖刺**（受击反弹）、
  **狂暴**（HP < 30% 反击 ×1.5）、**护盾再生**（护盾被击穿后按回合恢复）
- **Roguelite 成长**：攻击力随等级提升；敌人的层级与稀有度（普通 / 稀有 / 史诗 / 传说）随等级解锁
- **武器库与战力**：击败**必掉 1 把武器**（普通 70% / 稀有 22% / 史诗 7% / 传说 1%，40 次保底），
  80 把武器**各有独立像素图与一段小故事**；「🎒 武器库」页按稀有度分组展示收集进度
- **战力有实际作用**：武器提供**百分比攻击加成**（普通 +8% / 稀有 +15% / 史诗 +25% / 传说 +40%）——
  等级攻击成长被刻意压低、缺口由武器补足；未手动装备时**自动取已拥有里战力最高的那把**（永不亏），
  也可以在武器库里固定装备自己喜欢的武器
- **技能书与技能库**：击败敌人有 **10% 概率掉「技能书」**（独立掉落池 + 连续 30 只未出稀有必掉一本）；
  **50 本**书各带 1 个标签（回复 / 护盾 / 连击增幅 / 必暴 / 贯穿 / 破甲 / 精准 / 追击 / 反震）与一句技能注记，
  9 个标签可凑出 **12 条组合**。「📖 技能库」页有收集进度、按稀有度分组、详情卡与「一键推荐」
- **4 个技能槽**：必须 **4 本不同的书、全手动装配**，空槽 = 普攻（装书永不劣于不装），换装免费可逆；
  每次攻击按权重 4/3/2/1 从已上阵的书里随机施放一本，常驻显示「倍率 ×N · 组合 N」
- **玩家血量与反击**：`maxHp = 30 + 等级 × 6`，**击杀即回满**（没有药水、不用维护）；敌人每次没被打死就反击一次，
  伤害按 `maxHp` 百分比（小怪 5% / 精英 3.5% / 头目 3%）。血量见底 = **被击退**：满血、换一只新怪、连击归零，
  **不降级、不丢武器 / 技能书 / 收集进度、不清经验**（该场无经验无掉落）
- **怪物库**：「📖 怪物库」页收录所有遭遇过的怪物——未遭遇=暗剪影、已遭遇未击败=灰调、已击败=彩色并累计次数；
  点选查看这只 Bug 怪物背后的「Bug 纪要」
- **装备展示**：在武器库详情卡点「装备此武器」，战斗页的**装备槽**就换成它（图鉴里有 ★ 标记）
- **跨会话存档**：等级 / 经验 / 战绩 / 武器库 / 怪物库 / 技能书与 4 个技能槽（旧存档自动视为 0 本、4 空槽）

## 命令

| 命令 | 说明 |
|---|---|
| `Nibble: 显示像素小生物（底部面板）` | 展开底部停靠视图 |
| `Nibble: 攻击一次` | 手动补一刀 |
| `Nibble: 打开武器库` | 查看收集进度与武器故事、装备武器 |
| `Nibble: 打开怪物库` | 查看 40 只「编程 Bug」怪物的收录 / 击败记录，读它们的 Bug 纪要 |
| `Nibble: 打开技能书` | 查看技能书收集进度、标签与组合，装配 4 个技能槽 |
| `Nibble: 在编辑器标签页中打开` | 放大到编辑器标签页 |
| `Nibble: 重置等级/经验/战绩` | 清空进度重新开始 |
| `Nibble: 显示/隐藏状态栏小生物` | 切换状态栏显示 |
| `Nibble: 关于匿名统计（发什么 / 如何关闭）` | 查看统计状态、一键关闭或重置匿名 ID |

## 设置

| 设置项 | 默认 | 说明 |
|---|---|---|
| `nibble.triggerMode` | `hook` | 战斗节拍来源：`hook`（配套插件提问即攻击）/ `onSave`（保存文件即攻击）/ `manual`（仅手动） |
| `nibble.statusBar` | `true` | 在状态栏显示小生物 |
| `nibble.autoOpenPanel` | `true` | 启动时自动展开底部面板 |
| `nibble.tickMs` | `400` | 刷新间隔（毫秒） |
| `nibble.telemetry` | `true` | 发送匿名激活统计（仅匿名 ID + 版本号，每天最多 1 次）；设为 `false` 后不再联网 |

> 只装扩展、没有配套插件时，把 `nibble.triggerMode` 改成 `onSave` 即可独立使用。

## 隐私

**本扩展唯一会联网的地方是"匿名激活统计"**，且从添加它的那个版本起就在更新日志里公开说明。

- 只发送 **2 个字段**：本机随机生成的**匿名 ID**（与账号/机器无关，可一键重置）+ **扩展版本号**。
- **不发送**：代码、文件内容、文件路径、项目名、提问内容、账号、邮箱、机器名、操作系统、地理位置。
  服务端**不保存 IP**，只累加"当天上报次数 / 当天去重活跃数 / 各版本次数"。
- **频率**：每台机器每天最多 1 次。上报失败静默忽略，不影响任何功能。
- **关闭方式**（任一即可）：把 `nibble.telemetry` 设为 `false`；或运行 `Nibble: 关于匿名统计` 点「关闭统计」；或关闭 IDE 全局遥测。
- 除此之外，扩展**不读取**你的代码、提示词或文件内容，只读自己那份游戏存档。

## 战斗推进怎么来的

扩展只负责**显示**。"提问即攻击"的节拍由同系列的 **CodeBuddy 插件**（仓库 `plugins/nibble`）通过
`UserPromptSubmit` hook 驱动，两者读写同一份存档：

```
${CODEBUDDY_PLUGIN_DATA}/save.json
（默认 ~/.codebuddy/plugins/data/nibble/save.json）
```

因此展示是**常驻、自动动画、零 token** 的；未装插件时可用 `onSave` / `manual` 模式或命令推进。

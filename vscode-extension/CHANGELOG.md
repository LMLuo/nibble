## 未发布

### 新增：连击（Combo）—— 连续专注变成看得见的强度

- **连续提问累积连击**：相邻两次攻击间隔 ≤10 分钟算连续；断连**静默归零、无惩罚**（连击是"当前状态"，不是会掉的资产）
- **≥10 连「起势」**：攻击 +10%，每连 +1%（封顶 +30%）；脚下出现主题色光环、头顶浮现 `×N` 徽标，战斗日志带 `（×N 连击）`
- **≥25 连「燃」**：光环 / 徽标 / 伤害飘字转亮金；掉落保底额外推进 1 步（加速保底到来）
- **≥50 连「超载」**：一次性演出（全屏闪白 + `COMBO ×N` 像素横幅 + 数据块飞散）
- **<10 连对画面与数值完全隐形**：照常写代码即可，连击自己累积；新增伤害飘字（怪物头顶，3 帧阶梯上浮）
- 全部视觉**纯程序化**（零新素材、零新权限、零联网）；存档新增 `streak` / `lastDmg` 字段，旧档按 0 连击自动兼容
- 平衡：连击加成**不影响零连击基线**（平衡回归与改动前逐格一致）；`NIBBLE_SIM_STREAK=30 node tools/balance-sim.js` 可评估高连击影响
- 设计文档：`docs/游戏升级规划/09-连击系统设计.md`

## 0.4.0

### 新增：武器战力系统（武器不再只是收藏品）

- 每把武器提供**百分比攻击加成（战力）**：普通 +8% / 稀有 +15% / 史诗 +25% / 传说 +40%，同稀有度拉平
- **等级攻击成长被刻意压低**（`4 + 2lv` → `4 + 1.2lv`），强度缺口交给武器 —— 不带武器明显更吃力，好武器明显更快
- **未手动装备时自动取已拥有里战力最高的一把**（永不亏）；也可在武器库固定装备某把（哪怕它不是战力最高的）
- 战力可见：战斗页装备槽与状态栏显示 `武器名 +25%`、面板新增 `🗡 攻击 N`、武器库详情卡显示 `战力 +25%` 与 `⚡ 当前生效中`、命令卡片新增攻击力一行
- 怪物 HP 曲线同步重算（`30 + 10(lv-1)` → `round(21 + lv*5.95)`），保证**持普通武器时的击杀节奏与 0.3.0 基本一致**（小怪约 5 击、精英约 11 击）

### 调整

- 伤害浮动由固定 `±2` 改为**按比例 ±10%**：低等级下固定抖动会把武器战力的差距抹平
- 「跟随最近获得」的展示回落取消，改为「自动·取最高战力」——避免新掉的普通武器顶掉手上的传说

### 说明

- 存档仍为 `v1`，无需迁移；旧档下次进游戏即按新公式结算
- 平衡回归工具：`npm run balance:sim`（输出各武器档位在各级 / 各 tier 的击杀回合数）

## 0.3.0

### 新增：怪物库（40 只「编程 Bug」怪物 + 遭遇/击败双状态图鉴）

- 敌人从 3 只扩充到 **40 只**，命名与故事全部取材自真实编程 Bug：小怪（空指针幽灵 / 无尽轮回蛇 / 差一错虫 …）、精英（内存泄漏巨蟒 / 竞态幽灵 / 死锁蛛 …）、头目（段错误泰坦 / 熵增病毒 / 祖传代码巨像 …）
- 新增**怪物库图鉴页**（面板「📖 怪物库」标签）：按 小怪 / 精英 / 头目 分组，未遭遇=暗剪影、已遭遇未击败=灰调、已击败=彩色 + 击败次数角标；点选格子查看该怪物的「Bug 纪要」与机制
- **遭遇即入库**：提问时遇到新怪物就自动收录；击败后点亮并累计次数（取代原来只显示一句随机文案的"捕获"）
- 命令 `Nibble: 打开怪物库`；`/nibble:nibble bestiary` 查看怪物库进度
- 战斗页显示层级与机制（如「竞态幽灵（精英·史诗）」，悬停可见「闪避 20%」）

### 调整：战斗难度分级（仅数值分级）

- 怪物 HP 按 **层级 × 稀有度 × 等级** 三重缩放：小怪 ×1.0 / 精英 ×2.0 / 头目 ×3.6，稀有度最高 ×1.6；等级成长曲线调陡
- 精英与头目带**机制**：护甲（每次减伤）、闪避、自愈、护盾（伤害减半）、分裂（首次濒死分裂成两只）
- 出现权重随等级解锁：小怪全程、精英 Lv6 起、头目 Lv15 起；等级越高杂兵占比越低
- 击败经验改为随怪物 HP 折算，避免怪物变硬后升级过快、反而更容易
- **不引入玩家 HP 与失败判定**：战斗节拍仍是"提问即攻击"，不会因为打不过而卡住

### 说明：旧存档兼容

- 存档版本仍为 `v1`，新增字段可缺省；旧档里 `bat / slime / mimic` 三只旧敌人会被替换为新怪物（等级 / 经验 / 战绩 / 武器库全部保留）

### 新增：匿名使用统计（提前告知，可一键关闭）

为了让作者知道**大概有多少人在用这个扩展**（市场页只显示累计下载量，看不出还有多少人在跑），
从本版本起扩展会在启动时发送一次**极简匿名上报**。我们选择把它写进更新日志，而不是悄悄加上：

**只发送 2 个字段：**

| 字段 | 内容 |
|---|---|
| 匿名 ID | 本机随机生成的一串随机字符（UUID），与你的账号、机器、项目**没有任何关联**，也无法反推回来 |
| 版本号 | 例如 `0.2.0` |

**不发送、也从未采集**：代码、文件内容、文件路径、项目名、提问内容、账号、邮箱、机器名、操作系统、地理位置。
服务端**不保存 IP 地址**，只累加几个计数（当天上报次数、当天去重活跃数、各版本次数）。

**频率**：每台机器**每天最多 1 次**（当天首次打开 IDE 时），版本升级后会补发一次做版本分布统计。
上报失败一律静默忽略，不影响任何功能，也不会阻塞启动或联网重试。

**随时可以关掉（三处任一即可生效）**：

1. 设置里把 `nibble.telemetry` 改为 `false`；
2. 命令面板运行 **`Nibble: 关于匿名统计（发什么 / 如何关闭）`** —— 会列出当前状态与"上次上报时间"，并可直接关闭统计、重置匿名 ID；
3. IDE 的全局遥测被关闭时（`telemetry.enabled` / `telemetry.telemetryLevel`），本扩展也不会发送。

如果你不希望参与，改完之后本扩展不会再发出任何网络请求——宠物、战斗、存档等全部功能不受影响。

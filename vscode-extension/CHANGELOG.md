## 0.6.7

### 小屋：未拥有家具点击给出提示（不再静默）

- **点击未拥有的单件（床 / 桌 / 椅 / 灯 / 地板 / 墙壁 / 地毯 / 装饰）**，仓库提示行会显示「『物品名』尚未拥有，击败敌人有几率掉落」——此前装饰有这条提示而皮肤件没有，点了没反应容易被当成按钮坏了（即"地毯应用不上"报告的根因：物品未拥有，应用逻辑本身没问题）
- **一键整套按钮同理**：未集齐整套时提示「还差『物品名』，集齐整套才能一键换装」，而不是无反应

## 0.6.6

### 小屋（家园）系统：等距 2.5D 装修玩法

**房间与渲染**

- **等距 2.5D 房间**：10×8 格地板 + 两面墙 + 门（给以后的屋内走动留的入场点）；WebGL2 渲染，canvas2d 自动兜底（`?force2d=1` 可强制，两条路径观感一致）
- **拖动吸附**：家具可拖动摆放，吸附到格子；非法位置红框并弹回原位；视图可平移（Shift 拖动 / 右键）、滚轮切换 1x/2x/3x
- **像素夜空背景**：程序化生成的星空（固定种子，星星位置稳定不闪），不再是一整块黑
- **家具落影**：每件家具带双层软阴影，不再像贴纸浮在地板上

**物品化模型（逐件搭配，不是整屋换套）**

- **8 个搭配槽位**：地板 / 墙纸 / 床铺 / 桌子 / 椅子 / 灯 / 地毯 / 摆件，**逐件挑**——「一套风格」是集齐 8 件后的自然结果，不是切换单位
- **40 件槽位物品** = 5 系列 × 8 槽位，稀有度跟随系列：暖木（普通）/ 旧书房、苔石（稀有）/ 霓虹（史诗）/ 星海（传说）
- **20 件通用装饰**：绿植 / 书架 / 沙发 / 猫爬架……（1×1 小件 10 / 2×1 中件 6 / 2×2 大件 4），跨系列中性配色；单间小屋最多摆 **16 件**
- **地板与墙纸可来自不同系列**：房间底图按「地板系列|墙纸系列」按需生成并缓存，混搭不受限
- **一键整套**：仓库顶部的系列快捷按钮，8 件集齐才可点，一键换齐整套
- **真实像素美术**：60 件全部来自 AI 生成的绿底排列图，经 `tools/furniture-sprites.mjs` 管线切片（14 色量化 + 孤立杂点并入），地板 / 墙纸为可平铺材质砖

**仓库与掉落**

- **右侧抽屉仓库**：固定宽 336px 靠右，打开时房间自动左移让位——「边看边摆」；装潢 / 装饰两页
- **槽位就地快换**：点左栏槽位行，直接弹出该槽 5 个选项浮层，点一下即换（换一件 2 步）
- **装饰跟随鼠标放置**：点装饰进入放置态——半透明幽灵跟随鼠标吸附格子，能放绿框 / 不能放红框，左键落地、右键或 Esc 取消；拿起中的格子高亮闪烁，舞台顶部有操作提示条
- **撤销**：`Ctrl+Z` 或底栏按钮，最近 12 步（换装 / 一键整套 / 摆收装饰 / 拖动全覆盖；失败的操作不占步）
- **单件掉落**：每次击败 **2%** 掉一件未拥有家具（稀有度决定权重），连续 **40 只**未出必掉一件；开局赠送整套暖木 + 6 件普通装饰，新玩家不会空手
- **存档兼容**：`v` 仍为 1，`home` 为可选字段（`skins / layout / owned / pity`）；老档自动补齐，保存搭配**不会**冲掉收集进度与保底计数

**修复**（本轮迭代踩掉的）

- WebGL 贴图上下颠倒：`uvOf` 把贴图上下边的 V 值写反（房间用手写 UV 侥幸没露馅）
- 房间底图整块不画：room key 在 drawList / ensureRoom / 纹理表三处各拼各的字符串，收口成 `roomKey()` 一处定义
- 独立样张页整页发黑：`.hidden` 只定义在 panel.html 的内联样式里，独立页面拿不到，仓库面板（98% 不透明）一直盖在画面上——`home.css` 自带一份
- 素材管线：AI 不守「3×2 网格」→ 改一张图 3 件横排 + 按内容空隙找刀口；"绿幕"不是纯绿 → 只在绿色像素里统计众数当背景色再按距离清除

## 0.6.1

### 修复：插件里没有攻击特效（面板收不到施放消息）

- **根因**：hooks 进程把「这一击用了哪本书」写进存档的 `lastCast`，但扩展是另一个进程、通过 `loadSave()` 的**逐字段白名单**读盘，`lastCast` 不在名单里 → 扩展永远读到 `undefined` → `type:'cast'` 从不推送。数值、日志、掉落、技能书页全都正常，唯独面板没有施放特效（官网演示自己造 cast，所以演示里反而有）
- **修复**：`loadSave()` 还原 `lastCast`（校验 `id` 属于技能库、`at > 0`），面板重新拿到拆相位所需的 `form / tier / frames / impactAt / killedEnemy / hpBefore…`
- **加固**：webview 的三个资源 URL 带 `?v=<version>`，换版本后不会再被 `file://` 旧缓存骗成"装了新版、跑的是旧脚本"
- **可诊断**：`scene.js` 暴露 `window.__nibbleScene.build`（从自身 `src` 读版本），一行命令即可区分"新代码没加载"与"没画出来"
- **自检**：`npm test` 新增第 6 项——`lastCast` 写盘后必须能读回，防止同类跨进程字段再被漏掉

## 0.6.0

### 技能书第五刀：施放管线与招式原语（表现层）

- **先出手、再打击、命中帧才结算画面**：一次施放拆成相位（起手 → 生成 → 命中 → 有追击才加追击 → 有反击才加反击）；命中帧之前，面板敌方血条、玩家 HP、击杀的怪名显示**出手前快照**，命中那一拍才掉到新值——不再"血先掉、特效后到"
- **击杀演出补齐时序**：击杀那一击，命中帧之前场景继续画"被打死的那只"（连场景主题一起冻结），管线播完后消散 6 帧，才让位给新怪与它的名字
- **玩家 HP 冻到反击拍**：未击杀时怪物会反击（第三刀），面板把玩家血量的扣减留到管线的反击帧才显示
- **12 个招式原语**（每本书配一个，纯表现不参与数值）：单点落雷 / 直刺 / 斩击 / 爆发 / 液滴 / 印戳 / 法阵 / 漩涡 / 层叠 / 字块 / 回旋补丁 / 多点骤雨——每个原语三段各自带拖尾、碎屑、地面痕迹等分层元素；首批指派 9 本样张，其余按标签兜底，样张通过后逐本补全
- **12 个原语各有主色、各有命中反馈**：主体与施放阵用招式主色（落雷金 / 直刺橙 / 斩击橙红 / 爆发火橙 / 液滴绿 / 印戳靛蓝 / 法阵淡蓝 / 漩涡紫 / 层叠琥珀 / 字块青 / 回旋粉 / 骤雨冰蓝），标签色只留给标签特效与横幅；命中反馈按配方组合（冲击波 / 余烬 / 碎块雨 / 刀光横扫 / 方块直落 / 多点溅射 / 击退 2 格 / 地面焦痕），法阵与液滴不再在敌人身上炸开
- **50 本书全部逐本指派招式**：原先只有 9 本样张指派、其余按标签兜底（同标签的书长得一样）；现在按书名的意象逐本指定（打印大法→字块、调用栈→叠块、二分定位→直刺、竞态雷达→漩涡……），同一标签内不重复原语——同标签的两本书也不会再撞同一套演出。`npm test` 新增自检：未指派 / 原语非法 / 同标签重复，任一命中就失败
- **施法姿态逐原语**：12 个技能不再共用「同一个脚下圆环 + 三粒聚能 + 同一记前冲」——起手按原语站位（直刺后撤 3 格蓄力 / 斩击·字块上步 1 格 / 落雷后撤 1 格），脚下法阵分四形态（逐拍外扩 / 向内收束 / 双环 / 不画），蓄能分五形态（头顶聚能 / 身后夹持 / 举印 / 叠块 / 身前滴落，字块与回旋交给招式自己画）
- **主角挨打也有了反馈**：反击帧不再只有「怪物前倾 + 火花飞过来」——主角整格暖红罩 180ms 衰减（白 = 敌人在掉血、红 = 我在掉血）、下压 1 格顿帧、被打退 1 格再站回；接触点亮一下白热并震出 3 粒暖红碎点，脚下压一圈小弧
- **击杀演出：打飞 + 碎裂 + 飞书**：被打死的那只从命中帧起被打飞出去（右移 12 格 + 抬空 5 格），同时从它自己的像素里抠出碎块抛散（颜色原样、抛物线落地），老的隔帧闪烁消散保留叠加；掉技能书时，书从尸体位置沿抛物线飞进右下角 4 个技能槽，落地炸一下才弹「获得技能书」提示（提示不再早于演出）
- **前冲挪到命中拍**：蓄力时人是退回去的，冲出与打击同一拍（突刺 5 格 / 斩击·字块 3 格 / 爆发·印戳·回旋 1~2 格 / 远程与自增益原地出手）；普攻仍走原来的前冲曲线
- **命中反馈加厚**：命中拍起敌人处播放冲击波环 + 8 粒暖色余烬 + 6 粒碎块雨（抛物线落地，每发落点固定不闪）；地面裂痕保留到本次施放播完；重击（史诗/传说）命中一瞬全场景罩一层暖白
- **施放横幅带书图标**：横幅左侧显示这本书的 24×24 像素图标（与图鉴同口径），稀有度色边框不变
- **攻击过程不再卡顿**：特效动画改由 rAF 按时间细步推进（相位内 60fps 连贯，坐标仍按格取整保持硬边），不再跟宿主 tick 一顿一顿；前冲改"冲出去再收回来"的半波曲线，被击中的怪物下压 1 格（命中顿帧），受击闪白按时衰减
- **飘字升级**：按时间上浮（不再跳格）；必暴那一击放大加金（`.dmg.crit`）；敌方血条解冻时宽度 220ms 线性过渡，掉血从"一格硬切"变成滑落
- **受击反馈**：命中那一拍敌人整格提亮 1 帧（半透明白罩，不盖住命中特效）；重档/必暴的抖屏从"收到施放"挪到命中拍
- 相位时钟由宿主随 `tick` 下发（`tickMs` 可配置，面板不自己数帧）；普攻（空槽）仍走老路：飘字跟 `lunge`、消散跟 `dissolve`，完全不受影响
- `npm run preview:html` 的样张页轮播**12 个原语各一发**（带全管线字段，与真机同一条数据通路），并新增 `__nibbleDemo` 调试钩子（hold/step/cast）用于自动化核对
- **官网演示同步**：首屏演示新增「✦ 技能书」页（50 本图鉴 / 4 槽 / 一键推荐）与战斗页 4 槽；装配会实时改倍率与组合，出手时播施放横幅，击杀按 10% 掉落技能书

### 技能书第四刀：技能特效（表现层）

- **每次施放都看得见**：抽中哪本，战斗页右下角的那一格就亮起；场景顶部弹出「书名 + 标签」横幅（重档史诗/传说标注"重击"、必暴再加"暴击"），1.2 秒后跳变消失
- **9 个标签各有像素特效**（纯程序化、零新素材）：必暴（命中十字星）／追击（残影虚线）／贯穿（硬线穿刺）／破甲（甲片飞散）／精准（头顶准星）／回复（绿点飞回自身）／护盾（身前蓝弧）／连击增幅（脚底金环）／反震（粉点回弹）
- **演出强度分三档**（轻 = 普通 / 中 = 稀有 / 重 = 史诗·传说）：重档施放环更大、横幅加金圈，并触发一次轻微抖动
- **普攻不受影响**：空槽仍是普攻——不出环、不出横幅、不高亮槽位，伤害飘字保持原样；技能飘字按标签色描边
- `npm run preview:html` 的样张页每 2.6 秒轮播一发施放样张（用技能库里已上阵那 4 本的真实书名，与技能页自洽）

### 技能书与技能库（第一刀：收集层）

- 击败敌人有 **10% 概率掉落「技能书」**：**独立掉落池与保底**（连续 30 只怪未出"稀有及以上"必掉一本稀有），掉率 55/24/15/6（普通/稀有/史诗/传说）
- 新增 **50 本技能书**（普通 20 / 稀有 15 / 史诗 10 / 传说 5），每本带 **1 个标签**（9 种：回复 / 护盾 / 连击增幅 / 必暴 / 贯穿 / 破甲 / 精准 / 追击 / 反震）与一句技能注记
- 新增 **技能书图鉴页**（导航第 4 项）：收集进度条、按稀有度分组、详情卡显示倍率 / 出手权重 / 标签效果 / 注记，以及"装上后会触发哪些组合"
- 新增 **4 个装备槽**（战斗页右下角，与左下角武器槽对称）：**必须 4 本不同的书、全手动装配**；**空槽 = 普攻（装书永不劣于不装）**、换装免费可逆、常驻显示「倍率 ×N · 组合 N」、详情卡提供「一键推荐」
- 状态栏 tooltip 同步显示技能书进度与已上阵数；首次获得技能书会点亮技能页入口（引导装配）

### 技能书第三刀：玩家血量与怪物反击（零惩罚风险层）

- **玩家有了血量**：`maxHp = 30 + 等级 × 6`，**击杀即回满**（没有药水、没有补给、不需要任何维护）；血量只被怪物扣减
- **怪物会反击**：每次攻击后、敌人未死时反击一次；伤害按玩家 `maxHp` 的百分比（小怪 5% / 精英 3.5% / 头目 3% × 稀有度），致死下数 20 / 28 / 33——**小怪与精英在任何配置下都不会把玩家打退，风险集中在头目**
- **血量见底 = 被击退**：满血 + 换一只新怪 + 连击归零，**不降级、不丢武器/技能书/收集进度、不清经验**（该场无经验无掉落，只白打一场）；面板播闪白 + 抖动，日志写明整句
- **8 种怪物属性**：现有 5 种（护甲/闪避/自愈/护盾/分裂）+ 新增 **尖刺**（受击反弹）/ **狂暴**（HP<30% 反击 ×1.5）/ **护盾再生**（护盾被击穿后每 N 回合恢复 1 层，上限=开场层数）；新 3 种只给精英与头目
- **三个风险层标签与四条组合开始生效**：回复（吸血，满血时转护盾）、护盾（下一次反击 -50% / 免疫一次）、反震（反弹所受反击的 50% / 100%）；组合：续航、铁壁（反击再 -25%）、血偿（反弹的一半回血）、以牙还牙（反弹 +25%）
- **界面**：状态栏心形条改为**玩家 HP**（tooltip 里同时给出敌方 HP）；面板数值区显示 `HP 42/78`（濒死转红）；敌人血条不变
- `npm run balance:sim` 新增**表 C：击退率**（自然血量下"这一场会不会在打死它之前被击退"），表 B 的回合数改为"纯伤害对拼"测量以保证与历史基线可比

### 技能书第二刀：随机出手与标签生效

- 每次攻击**按权重 4/3/2/1 从已上阵的 4 本里随机施放 1 本**（普通 ×1.00 → 传说 ×1.30；4 槽同档另有共鸣 +5%，全传说 +10%）；**空槽 = 普攻**，装书永不劣于不装
- **9 个标签本刀生效 6 个**：连击增幅（按"连击 +2/+4"算加成）、必暴（×2/×2.5）、贯穿（无视护甲与护盾格挡，强档再削 1 层）、破甲（无视护甲 + 额外削 1/2 层护盾）、精准（无视闪避，强档再无视护盾减半）、追击（追加 50%/100% 伤害，**不吃减伤、不再抽签、不触发反击**）
- **12 条组合本刀生效 8 条**：暴走（暴击 +1 连击）、破防重击、连环（追击 +1 连击）、致命、粉碎（贯穿直接清盾）、重影（追击吃暴击倍率）、锁影（追击再 +25%）、气势（连击加成再 +3%）
- 「回复 / 护盾 / 反震」三个标签与「续航 / 铁壁 / 血偿 / 以牙还牙」四条组合**已占位但不参与结算**：它们的对象是"怪物反击 / 玩家血量"，随第三刀自动生效

### 新增：匿名使用统计（提前告知，可一键关闭）

为了让作者知道**大概有多少人在用这个扩展**（市场页只显示累计下载量，看不出还有多少人在跑），
从本版本起扩展会在启动时发送一次**极简匿名上报**。我们选择把它写进更新日志，而不是悄悄加上：

**只发送 2 个字段：**

| 字段 | 内容 |
|---|---|
| 匿名 ID | 本机随机生成的一串随机字符（UUID），与你的账号、机器、项目**没有任何关联**，也无法反推回来 |
| 版本号 | 例如 `0.2.0` |

**不发送、也从未采集**：代码、文件内容、文件路径、项目名、提问内容、账号、邮箱、机器名、操作系统、地理位置。
服务端**不保存 IP 地址**，只累加几个计数（当天上报次数、当天去重活跃数、各版本次数）。

**频率**：每台机器**每天最多 1 次**（当天首次打开 IDE 时），版本升级后会补发一次做版本分布统计。
上报失败一律静默忽略，不影响任何功能，也不会阻塞启动或联网重试。

**随时可以关掉（三处任一即可生效）**：

1. 设置里把 `nibble.telemetry` 改为 `false`；
2. 命令面板运行 **`Nibble: 关于匿名统计（发什么 / 如何关闭）`** —— 会列出当前状态与"上次上报时间"，并可直接关闭统计、重置匿名 ID；
3. IDE 的全局遥测被关闭时（`telemetry.enabled` / `telemetry.telemetryLevel`），本扩展也不会发送。

如果你不希望参与，改完之后本扩展不会再发出任何网络请求——宠物、战斗、存档等全部功能不受影响。

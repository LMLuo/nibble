    HOW IT WORKS

    它是怎么打怪的

    › if (prompt) nibble.attack() // 你说一句，它打一下
    1

    你提问

    在 CodeBuddy 里提问、或保存一次文件 → 触发一次攻击。触发方式可切：nibble.triggerMode 支持 hook（提问即攻击，默认）/ onSave（保存即攻击）/ manual（只点按钮）。

    2

    它出手

    小狗前冲、怪物掉血。每只怪物都有机制——闪避、护甲、护盾、自愈、分裂，精英与头目还会尖刺反弹、狂暴、护盾再生；遭遇即自动收录进「📖 怪物库」。连续提问累积连击：≥10 连攻击最多 +30%、脚下亮起光环；≥25 连转亮金；≥50 连超载演出。断连静默归零，不惩罚。

    3

    击败就掉武器

    击败必掉 1 把武器（{{DROP_ODDS}}，{{PITY_LIMIT}} 次保底）。{{WEAPON_TOTAL}} 把各有独立像素图与一段小故事。

    4

    武器真有用

    每把武器提供战力加成：{{POWER_ODDS}}。不手动装也会自动取已拥有里最强的那把，也可以在图鉴里固定携带（★ 标记）。

    5

    还会捡到技能书

    击败敌人有 {{SKILL_DROP}} 概率掉一本技能书：共 {{SKILL_TOTAL}} 本、{{SKILL_TAGS}} 种标签、{{SKILL_COMBOS}} 条组合，连续 {{SKILL_PITY_LIMIT}} 只没出稀有会保底一本。「📖 技能书」页收集与查看，可自由装配 4 个技能槽——空槽就是普攻，装书永不劣于不装。

    6

    怪物也会反击

    拾玖有血量（30 + 等级 × 6，击杀即回满），怪物没被打死就会反击。血量见底只是被击退一场：满血、换一只新怪，不降级、不丢武器 / 技能书，该场无经验无掉落。

    战斗数值全在本地算：不调用任何模型 API、不多花你一分钱（零 token），存档写在 ~/.codebuddy/plugins/data/nibble/save.json，跨会话、跨窗口都接着打。

    INSTALL

    装到编辑器

    方式 1 · 装扩展推荐，开箱可用

    VS Code 用 Visual Studio Marketplace；CodeBuddy / VSCodium / Cursor 用 Open VSX。两边都搜 Nibble，或命令面板执行：

    Extensions: Install from VSIX...

    默认保存文件即攻击，不需要其他依赖；装完状态栏就会出现它。

    方式 2 · 装插件 → 提问即攻击默认玩法

    CodeBuddy · 终端
    /plugin marketplace add "<本仓库目录>"
    /plugin install nibble@nibble-cb
    /reload-plugins
    /nibble:nibble-setup

    需要 Node ≥ 16；Windows 下 CodeBuddy 的 hooks 走 Git Bash，故需安装 Git for Windows。

    方式 3 · 免安装桌面版Windows

    不想开编辑器？nibble-desktop 是独立的桌面伴生版：免安装单文件 exe（约 70 MB），双击就常驻桌面，在任意程序里敲空格 / 回车即攻击——只观察不拦截，正常打字完全不受影响。

    Nibble-Portable-*.exe

    到 Releases 下载后直接双击运行；存档在 %APPDATA%\Nibble，零联网。首次运行 Windows 可能弹 SmartScreen 提示，点「更多信息 → 仍要运行」即可。

    常用的几条

    • Nibble: 显示像素小生物（底部面板）
    • Nibble: 攻击一次
    • Nibble: 打开武器库 / Nibble: 打开怪物库 / Nibble: 打开技能书
    • Nibble: 重置等级 / 经验 / 战绩
    • Nibble: 关于匿名统计（发什么 / 如何关闭）

    设置项：nibble.triggerMode、nibble.statusBar、nibble.tickMs、nibble.telemetry。

    PRIVACY

    隐私：不读你的代码

    不读你的代码、提示词、文件路径或文件内容。只在你每天第一次打开编辑器时发送 2 个字段——匿名 ID（本机随机生成）+ 版本号；可在设置中一键关闭，上报失败一律静默忽略。

    想彻底关掉，三种方式任选

    • 设置里关：nibble.telemetry = false
    • 环境变量：NIBBLE_NO_TELEMETRY=1
    • 关闭 IDE 自身的遥测开关（插件会跟随）

    玩法完全在本地：怪物数值、掉落、存档都不联网。唯一的联网点是这一次匿名统计。

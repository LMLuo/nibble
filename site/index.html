    HOW IT WORKS

    它是怎么打怪的

    › if (prompt) nibble.attack() // 你说一句，它打一下
    1

    你提问

    在 CodeBuddy 里提问、或保存一次文件 → 触发一次攻击。触发方式可切：nibble.triggerMode 支持 hook（提问即攻击，默认）/ onSave（保存即攻击）/ manual（只点按钮）。

    2

    它出手

    小狗前冲、怪物掉血。每只怪物都有机制——闪避、护甲、护盾、自愈、分裂；遭遇即自动收录进「📖 怪物库」。

    3

    击败就掉武器

    击败必掉 1 把武器（{{DROP_ODDS}}，{{PITY_LIMIT}} 次保底）。{{WEAPON_TOTAL}} 把各有独立像素图与一段小故事。

    4

    武器真有用

    每把武器提供战力加成：{{POWER_ODDS}}。不手动装也会自动取已拥有里最强的那把，也可以在图鉴里固定携带（★ 标记）。

    战斗数值全在本地算：不调用任何模型 API、不多花你一分钱（零 token），存档写在 ~/.codebuddy/plugins/data/nibble/save.json，跨会话、跨窗口都接着打。

    INSTALL

    装到编辑器

    方式 1 · 装扩展推荐，开箱可用

    在 Open VSX 市场 搜索 Nibble 安装，或命令面板执行：

    Extensions: Install from VSIX...

    默认保存文件即攻击，不需要其他依赖；装完状态栏就会出现它。

    方式 2 · 装插件 → 提问即攻击默认玩法

    CodeBuddy · 终端
    /plugin marketplace add "<本仓库目录>"
    /plugin install nibble@nibble-cb
    /reload-plugins
    /nibble:nibble-setup

    需要 Node ≥ 16；Windows 下 CodeBuddy 的 hooks 走 Git Bash，故需安装 Git for Windows。

    常用的几条

    • Nibble: 显示像素小生物（底部面板）
    • Nibble: 攻击一次
    • Nibble: 打开武器库 / Nibble: 打开怪物库
    • Nibble: 重置等级 / 经验 / 战绩
    • Nibble: 关于匿名统计（发什么 / 如何关闭）

    设置项：nibble.triggerMode、nibble.statusBar、nibble.tickMs、nibble.telemetry。

    PRIVACY

    隐私：不读你的代码

    不读你的代码、提示词、文件路径或文件内容。只在你每天第一次打开编辑器时发送 2 个字段——匿名 ID（本机随机生成）+ 版本号；可在设置中一键关闭，上报失败一律静默忽略。

    想彻底关掉，三种方式任选

    • 设置里关：nibble.telemetry = false
    • 环境变量：NIBBLE_NO_TELEMETRY=1
    • 关闭 IDE 自身的遥测开关（插件会跟随）

    玩法完全在本地：怪物数值、掉落、存档都不联网。唯一的联网点是这一次匿名统计。

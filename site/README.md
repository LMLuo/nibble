# `site/` —— Nibble 官网（手写单页，无框架无构建链）

推广 nibble 的落地页。纯 HTML/CSS/JS，零依赖、零外部请求（字体也是子集化后随仓库走的 woff2）。
发布走 `.github/workflows/pages.yml` → GitHub Pages。

## 怎么跑

```bash
npm run site                # 组装到 _site/ 并起本地预览（http://127.0.0.1:4600）
node tools/build-site.js    # 只组装（_site/ 已在 .gitignore，产物完全可再生）
npm run font                # 改了文案/数值后重跑：重新子集化像素字体
npm run site:check          # 三条硬线自检（体积 / 字体覆盖 / 零外部请求 / 降级规则是否还在）
```

- **文案与数值只有一份真源**：`site/index.html` 里的 `{{占位符}}` 由 `tools/build-site.js` 从
  `plugins/nibble/hooks/nibble.js` 等真数据填充。**别把手写数字写进 HTML**。
- 怪物名 / 武器名 / Bug 纪要原文一律从仓库取，不要自己编。

## 三条硬线（改任何东西都要守住）

| 硬线 | 数字 | 怎么守 |
|---|---|---|
| ① 手机"能滑不卡" | 375×667 + 4× CPU 节流整页滚动，长任务 ≤ 2 个 / 合计 ~142ms | **任何新动画都必须带降级**：CSS 动画靠 `[data-idle]` 出视口冻结，自走定时器用 `asleepIn()` 自己判 |
| ② 体积 | 单次改动 ≤ **+200KB**（基线见 `tools/site-baseline.json`） | 不要引外部库 / 大图；素材仅限 ≤20KB/件 |
| ③ 正文对比度 | ≥ **7:1** | 用 `tools/check-site.mjs` 与改配色后重跑浏览器实测（见下） |

> 基线**只在发版时重设**：`node tools/check-site.mjs --rebase`（会写新的字节数 + 日期）。
> 最近一次：**2026-10-19（893 KB）** —— 技能书演示上线，50 张 24×24 图标让演示数据涨了约 61 KB，
> 加上此前 0.5.x 战斗页重做与技能书四刀累计到 893 KB。**平时改动不要随手 rebase**：它等于把保护线往后挪，
> 单次新增仍要守住 +200KB。

实测留档（2026-10-12，Chromium，375×667，4× CPU 节流，整页 9750px）：
三段跳 **2 个长任务 / 最差 81ms**；关掉降级（粒子回来 + 出视口继续动）**24 个 / 最差 163ms**。

## 视觉语法（别破坏）

1. **字号只能是 12 的整数倍**：`--f1:12px`（正文/小字）、`--f2:24px`（卡片标题/按钮）、`--f3:36px`（h2）、
   `--f4:48/60px`（h1）。像素字体（`NibblePixel`，方舟像素字体 OFL-1.1）只在整数倍上不糊。
   文件末尾有一段"全站字号统一压到 12 的整数倍"的规范化规则，**新写的选择器请直接写 `var(--f1)`**。
2. **0 圆角 + 缺口 `clip-path` + 粗底边假立体**；圆角只留给"模拟终端窗口"（`.ide`/`.term`）。
3. **动画一律 `steps()`**，不要缓动。
4. **天光只有一套变量**（见下），不要在段落里另写死颜色。

## 滚动即一天（③ 的托底）与出视口暂停

- `site.js` 的 `buildTod()` 按"视口 40% 线落在哪一段"给 `<html>` 写 `data-tod="dusk|night|deep"`；
  CSS 里三个时段**只改天光**：天空色带 / 山脊 / 丘陵 / 地面色阶 / 各段环境色罩（`.bg .wash` 叠一层 `--tod-tint`）/
  星星亮度 / 顶栏 24 格进度条的颜色。**段落自己的地色与 `--wash` 不动**——那是"不同地方"的标识，不是天光。
- 首屏**故意不加天光层**：它按定义永远是黄昏（时段跟着滚动走，滚回顶部就回到黄昏），加了只会提亮字底下的天空、
  拉低对比度（实测 `--dim` 在最亮那条天空带 sky4 上只有 4.9:1，所以首屏小字也改用了 `--text`）。
- `buildIdle()` 用 IntersectionObserver 给滚出视口的段落挂 `data-idle`，CSS 里整段 `animation-play-state: paused`
  （实测运行中动画 220 → 7）。**新加的自走 `setInterval` 要自己判 `asleepIn(el)`**，CSS 管不住它们。
- **连续插值版只在 ≥1024px 开**（`@supports (animation-timeline: scroll())`）：实测它在 375 宽下会把长任务
  从 2 个抬到 25 个，所以窄屏一律走三段跳。若哪天想彻底关掉：删掉 `site.css` 末尾那个 `@supports` 块即可，
  三段跳本来就能独立工作。
- 窄屏（≤640px）关掉"微粒层"（`.dust/.glyphs/.fly/.rain/.campstars/.sparks/.fog/.scan/.sweep`，约 96 个动画节点）；
  静态装置全留，画面不会变空。

## 首屏那个"把 Bug 丢给它"（记忆点）

- 内容侧在 `tools/build-site.js` 的 `BUG_WORDS`（**40 只怪必须全覆盖，漏一只或写错 id 构建会直接报错**），
  构建期注入 `_site/demo-data.js` 的 `bug` 字段。
- 前端在 `site/site.js` 的 `2.5)` 一节：FNV-1a 哈希 → 命中词最长者胜 → 代号式假名
  「〈前缀〉的〈档位生物〉 · 〈你的词〉」→ 确定性战报（"预计几击"按 `attack()` 的真实规则算，闪避按期望折算）
  → `spawnEnemy()` 直接换掉演示面板里那只真怪（走与 IDE 相同的 state 消息）。
  中文长词**不要**再退回"前缀+词+后缀"黏连（「内存一直涨魔」读不通）。
- **隐私口径**：纯前端计算，不上传、不联网、不写 localStorage；只有访客点「复制分享链接」时才把原话写进 URL。
  `?bug=` 打开即复现同一只怪（同一输入 → 同一只怪、同一假名、同一份战报，靠哈希保证）。
  别往里加任何形式的输入上报。

## 素材口径（2026-10-12 用户拍定，取代旧的"不新增任何图片素材"）

- **天空 / 地形 / 光 / 粒子永远代码画**——那是换肤与体积的护城河。
- 只有"具体物体"（咖啡机、纸箱、打字机…）允许 AI 出图：**≤20KB/件、总量 ≤6 件**。着色用"全色 PNG + 夜里
  统一叠一层夜色与暖光锥"，本身是纯色的物件可以用形状蒙版 + CSS 变量着色。**不要做每件昼夜两版**（体积翻倍）。
- **管线已有实现：`tools/site-art.mjs`**。AI 出的"像素风"图其实不是像素画——一个逻辑像素内部有几十种色（噪声）、
  常有"假透明"（棋盘格烤进画面）、还可能被存成 JPEG（有损彩边），直接放进页面会又脏又大。它做四件事：
  **抠背景 → 按指定密度重建网格（每格取块内投票后的平均色）→ 量化到 ≤14 色 → 去孤立点**。
  ```bash
  node tools/site-art.mjs --probe legacy-mods/assets/dog.png   # 先看规格：背景形态 / 有效范围 / 自动探测的逻辑像素
  node tools/site-art.mjs --cells 72                           # 出图（--cells = 目标网格高度，格）
  ```
  输出 `site/og.png`（1200×630 社交分享卡，≈11KB）与 `legacy-mods/preview/shijiu-portrait.png`（立绘预览，
  gitignore 里、不进站）。实测：拾玖的源图 1254×1254 / 914KB / 9 万色 → **59×74 格 / 14 色 / 9KB**。
  注意：源图的"逻辑像素"并不均匀（自动探测纯度只有 79.8%），所以密度必须由 `--cells` 明确指定，别信探测值。

## 改配色 / 改文案之后

1. 配色：`site/site.css` 顶部的 `:root` 是唯一入口（页面层已比扩展面板整体提亮；
   **演示面板内部保持扩展原色**，别为了统一把它也提亮）。
2. 文案：改完 `npm run font`（构建会用 `site/fonts/charset.txt` 比对，缺字会打警告）。
   注意顺序：`font` 会把**上一次构建产物 `_site/`** 一起扫进去，所以改的是**仓库数据**（怪物/武器/技能书的注记等）时
   要走 **build → font → build**；只跑一次 font 会漏掉新数据里的字（构建时会报"N 个字符不在字体子集里"）。
3. 对比度：改完用真浏览器复测一遍。可复用的量法——取文本 `color`，与"段落底色上叠一层天光色罩"的合成色算 WCAG 比值
   （天光色的解析值可从 `.scene::after` 的 `backgroundColor` 读到）。2026-10-12 实测区间 7.65~18.63:1。
4. 首屏地形边（`.sec-edge`）的锯齿色是从 `getComputedStyle(sec).backgroundColor` 烤进 SVG 的，
   **改了段落底色要重跑一次页面**（刷新即可，构建期不受影响）。

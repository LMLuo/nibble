# 10 · 技能书与技能库设计

**定位**：把"随机出手"从想法变成可收集的东西——击败敌人**低概率掉落技能书**，50 本分四档稀有度、9 个标签、12 条组合；填满 **4 个装备槽**后，每次攻击**随机施放一本**（乘法叠加、权重轻/中/重）。
**状态**：设计定稿待审（本刀只交付收集层：掉落 + 技能库 + 4 槽装配；出手层紧随其后）。
**依赖**：`07-武器库收集系统设计.md`（收集范式与装备交互）、`09-连击系统设计.md`（三条筛子）、`11-玩家血量与怪物反击设计.md`（第三刀，反击值决定"回复/护盾/反震"三个标签的实际价值）。

---

## 一、设计决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 技能书从哪来？ | **击败掉落，独立池** | 不与武器池共用保底，避免稀释 80 把武器的长线节奏 |
| 规模？ | **50 本**（普通 20 / 稀有 15 / 史诗 10 / 传说 5） | 4 槽需要"每本都有辨识度"，且要撑起 12 条组合的搭配空间 |
| 每次击败掉率？ | **10%**，另有**独立保底 30 只怪** | 实测掉书率 11.6%（≈每 8.6 只怪一本）：4 槽填满约 1~2 周，集齐 50 本是大长尾（见第五节） |
| 保底给谁？ | **稀有及以上** | 技能书池小，每本都要能上场；不与武器的"史诗保底"同档 |
| 重复书怎么办？ | **纯计数**（×N 显示） | 与武器库一致；不引入合成/升星（违背"不复杂"） |
| 每本的差异在哪？ | **一个标签**（9 种之一）+ 两档强度 | 机制全部"自动判定"，不需要玩家在战斗中做任何操作 |
| 怎么玩出搭配？ | **12 条标签配对 + 1 条稀有度共鸣** | 组合由"标签组合"推导，不由具体书 id 推导 → 加书不改组合表 |
| 技能伤害怎么算？ | **乘法叠加**：倍率 1.00 / 1.10 / 1.20 / 1.30（按稀有度） | 与连击、武器战力同一套乘法因子；普通档 = 1.00 = 普攻 |
| 出手怎么随？ | 4 槽**按稀有度权重随机出 1 本**（权重 4/3/2/1） | 高稀有度 = 更低概率 + 更高倍率 → 重击高光 |
| 装备槽？ | **4 槽，必须 4 本不同的书**，全手动装配 | 禁止重复上阵，否则"最优解＝最强那本塞 4 次"，随机会退化成恒定输出 |
| 手动的负担怎么办？ | **四条护栏**（见第六节） | 守住筛子第 2 条：不出现"点错会亏"的决策 |
| 素材？ | **50 张独立 24×24 像素图标** | 与武器/怪物同管线；先出 12 张样张定画风 |
| 数据放哪？ | `plugins/nibble/hooks/skills.js` + `skills-stories.js` + `skills-pixels.js` | 与 `weapons*.js` 完全同构，零依赖、随 `sync-lib` 进扩展 |

## 二、为什么是技能书（筛选过程）

`09` 定的前置口径（原文）：

> 玩法升级必须先过三条筛子：
> 1. **无负担**：不新增"必须做的事"（打卡、维护、资源管理）；
> 2. **无（误）操作负担**：不新增"可能点错、错了会亏"的决策（挑武器、加点、**技能选择**）；
> 3. **不复杂**：不加新系统层（货币、背包、合成、进化树管理）。

筛子表里 `❌` 的项目包含「属性克制 / 战斗策略三选一 / **技能释放**」，理由是"玩家要选，选错会亏"。本设计**正面撞上这一条**，必须逐条论证：

| 筛子风险点 | 本设计如何处理 | 判定 |
|---|---|---|
| 技能释放要玩家选时机 | **战斗内零操作**：每次攻击自动从 4 槽按权重抽 1 本，玩家看不到"选技能"这个动作 | ✅ |
| 技能选择错了会亏 | 四条护栏：① **空槽 = 普攻（倍率 1.00 = 普通档）**，装书永不劣于不装；② 换装**永久免费、无冷却、无消耗、随时可改**；③ 面板显示"当前期望倍率 + 已触发组合"，结果可见；④ 一键「推荐上阵」，手动只是默认路径 | ✅ |
| 会不会变成新系统层 | 没有货币、没有背包、没有合成，只有"一个收集表 + 4 个槽位" | ✅ |
| 会不会变成属性克制 | 标签与怪物属性只做**自动对位**（见 `11` 第六节），只影响效率、不影响"能不能过"，玩家不必看怪换装 | ✅ |

一句话：**这是"可逆的偏好表达"，不是"会亏的决策"**——它和 `07` 的武器战力（v0.4.0 起武器可手动装备、可一键跟随最高战力）是同一个量级的东西，只是多了 4 个槽。

## 三、技能书构成（50 本）

### 3.1 稀有度、倍率与出手权重

| 稀有度 | 数量 | 倍率 | 出手权重 | 标签强度 |
|---|---|---|---|---|
| 普通 | 20 | **1.00** | 4 | 弱档 |
| 稀有 | 15 | **1.10** | 3 | 弱档 |
| 史诗 | 10 | **1.20** | 2 | 强档 |
| 传说 | 5 | **1.30** | 1 | 强档 |

- **倍率区间 1.00~1.30**：刻意收得很窄。它是乘在「等级基础攻击 ×（1 + 武器战力% + 连击%）」之上的第三层因子，区间一放宽，三因子连乘就会把敌人 HP 配平表冲掉。
- **普通档 = 1.00 = 普攻**：这是护栏 ① 的硬保证（装书永不劣化），同时让"普通书"的价值落在标签上（它是组合件）。
- **权重 4/3/2/1**：同一把书越稀有越低概率出手 → 低概率高倍率 = 可感知的"重击高光"。
- **每次攻击恰好抽 1 本**；0 槽时打普攻；**追击标签的追加一击不再抽第二本**（防连锁）。

> ⚠️ 数值口径：倍率、权重是常量（`SKILL_POWER` / `SKILL_WEIGHT`），改动必须同步本节 + 跑 `npm run balance:sim`（见第十三节）。

### 3.2 九个标签

| 标签 | 键 | 弱档（普通/稀有） | 强档（史诗/传说） | 结算位置 | 生效于 |
|---|---|---|---|---|---|
| 回复 | `leech` | 本次伤害的 8% 转为自身 HP | 15% | 攻击结算后 | ✅ 第三刀 |
| 护盾 | `guard` | 下一次反击伤害 **-50%** | 免疫一次反击 | 反击结算前 | ✅ 第三刀 |
| 连击增幅 | `surge` | 本次攻击按"连击 +2"计算加成 | 按"连击 +4"计算 | 攻击结算前 | ✅ 第二刀 |
| 必暴 | `crit` | 本次伤害 **×2** | ×2.5 | 攻击结算时 | ✅ 第二刀 |
| 贯穿 | `pierce` | 本次无视护甲与护盾格挡（**不减半、不消耗层**） | 同左，且**额外削 1 层护盾** | 减伤结算时 | ✅ 第二刀 |
| 破甲 | `rend` | 本次无视护甲；**额外削 1 层护盾** | 无视护甲；额外削 2 层 | 减伤结算时 | ✅ 第二刀 |
| 精准 | `aim` | 本次无视闪避 | 无视闪避 + 无视护盾减半（**仍消耗 1 层**） | 命中判定时 | ✅ 第二刀 |
| 追击 | `chase` | 追加一次 **50%** 伤害 | 追加一次 **100%** 伤害 | 攻击结算后 | ✅ 第二刀 |
| 反震 | `reflect` | 本回合所受反击的 **50%** 反弹 | 100% 反弹 | 反击结算后 | ✅ 第三刀 |

- **每本恰好 1 个标签**，不存在"无标签技能"（否则 50 本会有一半是纯数字，收集欲起不来）。
- **强度只两档**（弱 = 普通/稀有，强 = 史诗/传说）：这是防止"50 本 × 9 标签 × 四档"炸成三维数值表的关键约束。
- 每个标签都**自动判定**、**不消耗任何资源**、**没有冷却**。
- **追击的追加一击**：不吃减伤（护甲/护盾不再结算一遍）、**不再抽签**、**不触发反击**（第三刀的红线——否则追击等于自伤）。
- **破甲与格挡叠加**：打在护盾怪身上，正常格挡消耗 1 层 + 破甲额外削 1/2 层 → 破甲的价值就是"加速击穿"。
- 三个风险层标签（回复/护盾/反震）的结算对象是"怪物的反击/玩家血量"，随 `11`（第三刀）**已全部生效**：吸血回血、护盾为"下一次反击"挂减伤、反震按比例反弹。

### 3.2.1 一次攻击的结算顺序（写死，实现时不得自由发挥）

```text
1) 抽签：4 槽按权重 4/3/2/1 抽 1 本（0 槽 = 普攻，倍率 1.00、无标签）
2) 连击：本次先计入连击；surge 标签按"连击 +N"重算本次加成（不改计数）；气势组合再 +3%
3) 伤害：atk × 技能倍率 × 稀有度共鸣 × 必暴(×2/×2.5) × 致命组合(×1.1) × 波动(±10%)
4) 命中：闪避判定（aim 标签无视）
5) 减伤：护盾格挡（半伤 + 消耗 1 层；pierce / aim 强档无视）→ 破甲削层 → 护甲（pierce / rend / 破防重击无视）
6) 落血 + 追击（若 chase）：追加一击独立结算，直接扣血
7) 连击组合：暴走（暴击 +1）、连环（追击 +1）
8) 敌人未死 → 自愈；归零 → 分裂；否则 → 击败（掉落/经验/刷怪）
```

## 四、组合搭配（12 条配对 + 1 条共鸣）

**判定规则**：只看"已上阵的 4 本"里**是否同时存在这两个标签**——不要求相邻槽位、不要求指定书名、不要求顺序。因此**加书不改组合表**（组合表挂在标签上，不挂在 id 上）。

| # | 组合 | 组成 | 效果 |
|---|---|---|---|
| 1 | 暴走 | 必暴 + 连击增幅 | 暴击时连击计数 **+1** |
| 2 | 破防重击 | 贯穿 + 必暴 | 暴击无视护甲与护盾 |
| 3 | 续航 | 回复 + 护盾 | 满血时吸血量转为护盾 |
| 4 | 连环 | 追击 + 连击增幅 | 追击命中也计入连击 **+1** |
| 5 | 致命 | 精准 + 必暴 | 命中且暴击时伤害再 **×1.1** |
| 6 | 粉碎 | 破甲 + 贯穿 | 护盾被贯穿时直接清零（而非只免格挡） |
| 7 | 铁壁 | 反震 + 护盾 | 反弹的同时，反击伤害再 **-25%** |
| 8 | 血偿 | 回复 + 反震 | 反弹伤害的 50% 也转为自身 HP |
| 9 | 重影 | 追击 + 必暴 | 追击也吃本次暴击倍率 |
| 10 | 锁影 | 精准 + 追击 | 追击的追加伤害再 **+25%**（锁定弱点） |
| 11 | 气势 | 连击增幅 + 回复 | 本次连击加成再 **+3%**（吸血那一半见 `11`） |
| 12 | 以牙还牙 | 破甲 + 反震 | 反弹伤害无视敌方护甲（第三刀） |

> 12 条组合**全部已生效**：8 条随出手层（第二刀）落地，4 条（3 续航、7 铁壁、8 血偿、12 以牙还牙）随风险层（`11`）落地。
> 第 10 条与第 11 条在实现时按上表口径收敛过措辞（原措辞描述的效果已被标签本身覆盖，等于空转）。

**稀有度共鸣（1 条）**：4 槽**同稀有度**时 → 本次倍率 **+5%**；4 槽全传说 → **+10%**。

- 组合效果**全部自动判定**，玩家只在"选书"时感知；面板显示「组合 N 条」。
- 组合是"倍率 vs 搭配"的取舍：塞入低倍率书会拉低期望倍率（权重表决定），**组合必须值回这个差价**——这正是手动装配的策略价值所在。
- `11` 中对位表保证：每个怪物属性至少有一条标签路径，12 条组合负责把"单标签"升级成"配合"。

## 五、掉落经济

| 项目 | 口径 |
|---|---|
| 池子 | **独立池**：武器必掉（既有）+ 技能书按 10% 掷；技能书保底计数与武器保底完全独立 |
| 掉率 | 每次击败 **10%** |
| 保底 | **30 只怪必掉**，且保底只给 **稀有及以上**（`SKILL_PITY_LIMIT = 30`） |
| 稀有度掉率 | 普通 **55%** / 稀有 **24%** / 史诗 **15%** / 传说 **6%**（`SKILL_RARITY_DROP`） |
| 重复 | 计入 `owned` 计数（×N 展示），**不消耗、不合成** |
| 首次引导 | 首次获得技能书：日志追加一句"去「技能书」页装配"；只要"有书但 4 槽全空"，面板持续点亮技能页入口（`skills.guide`） |
| 收集曲线（**实测**） | 20000 次击杀模拟：**掉书率 11.6%**（≈每 8.6 只怪一本）→ **首本 @30 只怪、4 槽填满 @51 只怪、集齐 50 本 @≈3500 只怪** |

- 按普通武器 5 击杀一只、每天 4~8 只怪折算：**首本约 1 周内、4 槽填满约 1~2 周**（手动装配的玩法在这一步就开始）；**集齐 50 本是长尾**（≈1~2 年），尾端几乎全在 5 本传说上——与武器库的传说同性质，属"收藏家的最后几格"。
- 调节奏的旋钮只有三个：`SKILL_DROP_RATE`（掉书概率）、`SKILL_PITY_LIMIT`（兜底）、`SKILL_RARITY_DROP`（稀有度分布）；改完必须跑一次掉落模拟并回写本节实测数字。
- 保底计数在 `skills.pity`，抽中"稀有及以上"即清零——与 `rollWeapon` 的 pity 语义同构。
- 技能书掉落**不影响**武器保底、**不影响**经验与等级。

## 六、装配与四条护栏

**槽位规则**
- 4 个槽，`null` = 空槽；**必须 4 本不同的书**（同一 id 只能占 1 槽）。
- **全手动装配**：获得新书**不自动替换**已上阵的书。
- 空槽不惩罚：0 槽 = 普攻（1.00），1~3 槽 = 按权重在已装的书里抽。

**四条护栏（守筛子 2）**

| # | 护栏 | 实现 |
|---|---|---|
| ① | **装书永不劣于不装** | 普通档倍率 = 1.00 = 普攻；且标签只加不减 |
| ② | **换装免费可逆** | 无消耗、无冷却、无次数限制；卸下/替换随时 |
| ③ | **结果可见** | 面板常驻「期望 ×1.18 · 组合 2」；详情卡显示该书的倍率/标签/强度/注记，以及"装上后会触发哪些组合" |
| ④ | **一键推荐上阵** | 按"倍率最高（含组合加成）"自动挑 4 本；按钮只省事，主动权仍在玩家（手动是默认路径） |

**交互（照 `07` 的装备范式）**
- 技能库格子点击 → 详情卡；详情卡底部一排 **4 个槽位按钮**（显示槽内当前书名），点哪个就装入哪个槽（覆盖）。
- 已上阵的书在格子上显示 `★`，与武器库一致。
- 战斗页 4 槽条点击 → 跳到技能库并选中该书。

## 七、数据与接口

**存档新增字段**（仍为 `v: 1`，全部可选、缺省补默认）

```js
skills: { owned: { [id]: count }, pity: 0 },   // 收集 + 独立保底
skillSlots: [null, null, null, null],          // 4 槽（顺序即展示顺序）
lastSkillDrop: { id, at }                      // 掉落 toast 用（仿 lastDrop）
```

解析口径（照 `parseArsenal` / `parseBestiary` 的防御式写法）：
- 未知 id **静默丢弃**；`count = Math.max(1, …)`；`pity = Math.max(0, …)`。
- `skillSlots`：长度补齐到 4；**只保留"已拥有"的书；同一 id 只保留第一处**（重复自动清空该槽）。

**模块职责**

## 八·补·五、施放管线与招式原语（第五刀·表现）

> **起因**：第四刀的特效在收到 `cast` 那一拍全画出来，但结算早已发生——看起来"血先掉、特效后到"。
> 第五刀把一次施放拆成**相位**，并给每本书配一个**招式原语**，口径只有一条：**先出手、再打击、命中帧才结算画面**。

### 8b.5.1 施放管线（相位）

| 相位 | 画面 | 面板状态 |
|---|---|---|
| 0 起手 | 施放阵（按原语四形态）+ 蓄能形态（按原语五形态）+ 起手站位（后撤/上步）+ 横幅/槽位高亮 | 敌方血条/玩家 HP 显示**出手前快照** |
| 1 生成 | 招式成形/飞行（原语的 travel 帧） | 同上（冻结） |
| 2 命中（`impactAt`） | 原语命中姿态 + 主角冲出（`dash` 格，远程/自增益为 0）+ 受击提亮 1 帧 + 伤害飘字 + 敌方血条掉到新值 | 解冻敌方血条；`killed` 的怪从下一拍开始消散 |
| 3 追击（有追击才加） | 第二击再闪一下 + 残影虚线 | — |
| 末帧 反击（`countered` 才有） | 怪物前倾 2 格 + 回击火花飞向玩家；**主角挨打**：整格暖红罩 180ms 衰减 + 下压 1 格顿帧 + 被打退 1 格 + 接触点白热与 3 粒碎点 + 脚下小弧 | 玩家 HP 解冻（玩家只会被反击扣血） |

- **快照口径**：`cast` 消息带 `hpBefore / maxHpBefore / playerHpBefore`——命中帧之前，面板血条、玩家 HP 数值、击杀的怪名全部显示旧值。顺序上**宿主先推 `cast` 再推 `state`**，否则会闪一帧新血量。
- **击杀换怪口径**：`killed` 时消息带 `killedEnemy`（含 sprite/tier/稀有度）——命中帧之前场景继续画"被打死的那只"（主题也跟着冻结），管线播完后消散 6 帧，才让位给新怪；怪名同步续到消散结束。
- **击杀演出（打飞 + 碎裂 + 飞书）**：命中帧起被打飞（右移 12 格 + 抬空 5 格，先快后慢，位置仍按格取整），同时从它**自己的像素**里稀疏抠出碎块抛出去（颜色原样取自身上，抛物线落地/超时即灭）；老的"隔帧闪烁消散 6 帧"保留，两者叠加而不是替换。
  技能书掉落时，书从尸体位置飞向右下角 4 个技能槽（700ms 抛物线、位置取整、缩放在 72% 处跳变，落地炸一下十字星），落地才弹 toast——面板内部用一条 `bookLanded` 消息把"飞书落地"和"提示弹出"对上拍（3.2s 兜底，防止场景层没跑时提示丢失）。
- **相位时钟在宿主**：`tickMs` 可配置，面板自己数帧会跟节拍脱钩——宿主在 `tick` 消息里带 `castPhase`（0..frames-1，-1 = 没在播），面板只跟不数。
- 普攻（空槽）没有 `cast` 消息：飘字仍走 `tick.lunge` 上升沿、击杀消散仍走 `tick.dissolve`——管线只是**叠加**，不改普攻的老路。

### 8b.5.2 十二个招式原语（逐本指派，纯表现）

`form` 由 `skills.js` 的 `SKILL_FORMS` 逐本指派（未指派的书按标签回落 `TAG_FALLBACK_FORM`），白热核心 + 重档命中撒金点。首批只指派 9 本样张（每标签 1 本，定"像不像"的基准）；**2026-10-19 已补全到 50/50 全显式指派**，按标签分组排（护盾 8 本、回复 7 本、精准·贯穿·必暴各 5~6 本……），同一标签内 12 个原语互不重复——跨标签撞原语允许（约束只在同标签内）。补全后 `npm test` 新增「技能书原语指派」自检：**未显式指派 / 原语非法 / 同标签内重复** 三项任一命中即失败。

**三条防"每个技能都长一样"的硬口径**（玩家反馈"特效重复"后补）：

- **主色逐原语**（`FORM_COLOR`）：主体与施放阵跟**招式主色**走，标签色只留给标签特效与横幅——落雷金 / 直刺橙 / 斩击橙红 / 爆发火橙 / 液滴绿 / 印戳靛蓝 / 法阵淡蓝 / 漩涡紫 / 层叠琥珀 / 字块青 / 回旋粉 / 骤雨冰蓝。同一标签的不同书也一眼分得开。
- **命中配方逐原语**（`HIT_STYLE`）：反馈件按招式组合，不再统一"炸一下"——
  冲击波（落雷/爆发）、余烬（落雷/斩击/爆发）、碎块雨（直刺/斩击/爆发/漩涡/层叠/字块）、刀光横扫（斩击）、方块直落（层叠）、多点溅射（骤雨）、击退 2 格（直刺）、地面焦痕（落雷/爆发/印戳/层叠）。
  **法阵 / 液滴 / 回旋 / 骤雨不在敌人处炸开**：法阵的反馈在自身（光柱），液滴是液花与液洼，回旋是"拍中—飞回"的两段节奏，骤雨是多点落星。
- **施法姿态逐原语**（`CAST_POSE`，玩家反馈"主角释放都是一套"后补）：起手两拍不再是"所有技能同一个脚下圆环 + 三粒聚能 + 同一记前冲"，改成三个维度按原语分——
  - `stance` 起手位移：后撤（落雷 -1 / 直刺 -3）是蓄力拖拽，前压（斩击 / 字块 +1）是上步；
  - `ring` 脚下法阵：`out` 逐拍外扩 / `in` 向内收束（蓄力感）/ `double` 双环 / `none` 不画；
  - `charge` 蓄能形态：`sky` 头顶聚能 / `lance` 身后夹持 / `lift` 举印 / `blocks` 叠块 / `drop` 身前滴落 / `none`（字块、回旋、斩击等招式自己画）。
  **前冲从起手拍挪到命中拍**：`dash` 记"命中冲出几格"（突刺 5 / 斩击·字块 3 / 爆发·印戳·回旋 1~2 / 远程·自增益 0）——
  蓄力时人是"退回去"的，冲出去与打击同一拍，节奏才是"蓄力—出手—命中"。普攻（无 `cast` 消息）仍走原来 `tick.lunge` 的正弦半波。

## 十、平衡与验收

- **敌人 HP 不上调**：技能倍率与武器战力、连击同口径——都是"玩家侧成长"，敌人不为它们补偿（`07` 的配平基准已经含"普通武器 +8%"，史诗武器同样没补偿）。收集的兑现就是"打得更快"。
  > ⚠️ 这条修正了评审时"敌人 HP 上调 +15~20%"的临时口径：那会让**还没凑齐技能书的早期玩家**整体变难，并让 `balance-sim` 的历史对照列失效（`09` 明确要求"零连击基线必须与改动前一致"）。
- `tools/balance-sim.js` 新增**"技能档"第三轴**（无技能 / 4 普通 / 4 稀有 / 4 史诗 / 4 传说）+ 每轮重置新增字段（`skills` / `skillSlots`，照 `:63-66` 的污染警示）。

## 十一、兼容、迁移与维护

**兼容**
- 存档仍 `v: 1`；旧档无 `skills` → 视为 0 本、4 空槽，**不影响任何既有进度**。
- 未知技能 id、超出 4 槽、槽内未拥有/重复的书 → 读档时静默清理。

**加一本技能书（五步，照 `07`/`08` 的"加内容"范式）**
1. `skills.js` 的 `SKILLS` 追加 `{ id, name, rarity, tag }`（id 唯一；倍率/权重由稀有度自动定档，不单独标数值）。
2. `skills-stories.js` 同 id 追加一句注记。
3. 排列图补素材 → 跑 `node tools/skills-sprites.mjs`。
4. `npm run sync`（同步 `lib/` 副本）。
5. 三载体截图核验：扩展面板技能页 / 官网预览 / 状态栏。

## 十三、变更规范

- **改掉率/保底** → 同步常量 + 本文档 + 跑 `npm run balance:sim`。
- **改倍率/权重** → 同步 `SKILL_POWER` / `SKILL_WEIGHT` + 本文档 + 重跑平衡 + **断言"普通档 = 1.00"**。
- **加/改标签** → 先过三条筛子 + 在标签表登记 + 检查 12 条组合与怪物属性对位是否仍完整。
- **加组合** → 登记在本节表格 + 确认不影响"装书永不劣化"。
- 技能书与技能数据**不进**任何联网/统计上报（与既有隐私口径一致）。

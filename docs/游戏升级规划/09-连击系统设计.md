# 09 · 连击（Combo）系统设计

**定位**：玩法层升级的第一刀 —— 把"连续专注地工作"变成**看得见的强度**。
**前置口径（必须先过的三条筛子）**：无负担 / 无（误）操作负担 / 不复杂。详见本文第一节。

---

## 一、为什么是连击（筛选过程）

玩法升级必须先过三条筛子：

1. **无负担**：不新增"必须做的事"（打卡、维护、资源管理）；
2. **无（误）操作负担**：不新增"可能点错、错了会亏"的决策（挑武器、加点、技能选择）；
3. **不复杂**：不加新系统层（货币、背包、合成、进化树管理）。

按此筛：

| 方向 | 判定 | 原因 |
|---|---|---|
| 属性克制 / 战斗策略三选一 / 技能释放 | ❌ | 玩家要选，选错会亏（违背 2） |
| 日常任务 / 打卡 / 积分经济 / 喂养小窝 | ❌ | 玩家要维护（违背 1） |
| 赛季 / 排行 / 组队 | ❌ | 需后端（违背 3） |
| **节奏响应类（连击 / 暴击 / 专注态）** | ✅ | 玩家照常提问，系统自己反应 |
| 自动判定类（行为画像进化） | ✅ | 自动长成形态（素材成本高，排期靠后） |
| 阈值事件类（里程碑 / 高光演出） | ✅ | 自动触发 |

连击是"节奏响应"里**最小、最快、复用现有节拍（提问即攻击）**的一个，所以先做它。

## 二、规则

| 项 | 值 | 说明 |
|---|---|---|
| 连击窗口 | **10 分钟** | 相邻两次攻击间隔 ≤ 窗口 = 连续；超过 = 从 1 重新数 |
| 生效门槛 | **≥10 连** | <10 对**数值与画面**都完全隐形 |
| 攻击加成 | +10%（10 连）→ 每连 +1% → **封顶 +30%**（30 连） | 与武器战力同层相加 |
| 档位 | 起势 ≥10 / 燃 ≥25 / 超载 ≥50 | 画面与事件的档位 |
| 断连 | **静默归零** | 无提示、无惩罚 —— 只奖励连续，不惩罚中断 |

档位效果：

- **起势（≥10 连）**：脚下光环 + 头顶徽标出现；战斗日志带 `（×N 连击）`
- **燃（≥25 连）**：光环 / 徽标 / 伤害飘字转**亮金**；掉落保底额外推进 1 步（加速保底，不改单次概率）
- **超载（≥50 连）**：一次性演出 —— 全屏闪白 + `COMBO ×N` 像素横幅 + 数据块飞散

> 连击是"当前状态"不是"资产"：超窗即视为 0（展示与生效同源），断连不掉任何东西。
> 断连的第二个来源：**被击退**（`11-玩家血量与怪物反击设计.md` 第五节）——血量见底时连击归零，口径与超窗断连完全一致（静默、无惩罚）。

## 三、画面表现（四层递进）

| 层 | <10 | ≥10 起势 | ≥25 燃 | ≥50 超载 |
|---|---|---|---|---|
| ① 脚下光环（canvas） | 无 | 主题色提亮版点阵椭圆弧 | 亮金满弧 + 弧顶白高光 + 上升粒子 | 同"燃" |
| ② 头顶徽标（DOM） | 隐藏 | 名字后 `×N`（主题色） | 转亮金 + 白边 | 同"燃" |
| ③ 伤害飘字（DOM） | 白字黑边 | 同左 | 转金 + 2px 厚描边 | 同左 |
| ④ 演出 | 无 | 无 | 无 | 闪白（.24）+ COMBO 横幅 + 飞散块/十字星 |

实现细则（都是踩过的坑）：

- **光环不能直接用主题 `accent`**：数据原野的 accent 与草地亮色恰好同色，第一版直接隐形。做法 = 提亮 72% + **每点下衬 1px 深色**。
- 光环只画"上弧 + 两侧下弧"（画满整圈会变"魔法阵"）；上升粒子用 2 帧跳变相位。
- 飘字 3 帧阶梯上浮（每帧跳 1 格，**不做平滑过渡**）；`<10` 不显示。
- 横幅与闪白 **1.6 秒后跳变消失**（不用渐变淡出）；一切显隐都是跳变。
- 断连的视觉 = 光环与徽标直接消失，**不播任何"可惜"提示**（只庆祝，不安慰）。

## 四、数据流

```text
提问 ──hook──▶ nibble.js: bumpStreak → 加成进 playerAtkWith → 日志带 (×N 连击)
                      │  存档新增字段：streak{count,lastAt} / lastDmg
扩展 tick(400ms) ─────┴─▶ buildState() 输出 streak / streakTier / streakBonus / lastDmg
                           ├─ key 变化（含 streak）→ 推 state → 面板更新徽标与光环
                           ├─ tick.lunge 上升沿 → 面板弹伤害飘字（取 state.lastDmg）
                           └─ 连击档位「跨入 ≥50」→ 推 {type:'burst'} → 闪白+横幅+飞散块
```

- 连击的**展示与生效同源**：`streakState()` 每次调用都会做窗口校验，过期自动回 0。
- `<50 → ≥50` 的跨越检测在扩展侧（`lastStreakTier` 比较）；断连后重新攒到 50 会再触发一次。

## 六、变更规范

- **改阈值/加成** → 同步 `STREAK_*` 常量 + 本文档 + 跑 `npm run balance:sim`（零连击基线必须与改动前一致）。
- **评估连击的强度影响**：`NIBBLE_SIM_STREAK=30 node tools/balance-sim.js`（30 连击 ≈ 击杀回合数 ×0.77）。
- **加新的档位效果** → 先过三条筛子，再在「档位效果」一节登记，并在画面表现表里补一列。
- 连击**不进**任何联网/统计上报（与既有隐私口径一致）。
